# Data-Cleaning-For-a-Cafe
## Overview
Python-based data cleaning project using Pandas library to identify, address and reconstruct missing and invalid values, format datasets and perform exploratory data analysis using visualisations.

## Dataset
- Source: Ahmed Mohamed via Kaggle
- Link: https://www.kaggle.com/datasets/ahmedmohamed2003/cafe-sales-dirty-data-for-cleaning-training/data
- License: CC BY-SA 4.0
- Rows: 10,000

## Objectives
- Address and reconstruct missing and invalid values
- Format dataset
- Exploratory Data Analysis
- Produce Visualisations

## Tools Used
- Python
- Visual Studio Code
- Pandas
- Kaggle

## Data Cleaning Process
- Investigate the dataset, identifying errors within the data that will be addressed:
  - Draw out first and last rows to identify any clear issues.
  - Check for duplicates in dataset.
  - Check the datatypes of each column.

- Correcting invalid values within non-numeric columns:
  - 'UNKNOWN' and 'ERROR' strings are present along side null values.
  - Replace these values with null values.

- Reconstructing missing values in numeric columns:
  - 'Quantity', 'Price Per Unit' and 'Total Spent' columns are mathematically related by: Quantity * Price Per Unit = Total Spent.
  - Locate the invalid and missing values.
  - Given that there are at least two recorded values, replace the invalid or missing values with the calculated result.
  - Values that could not be calculated are replaced by null values.

- Identifying missing items:
  - Identify the price of each item.
  - Items with unique prices can be identified, while items that share prices will require more information to be identified.
  - Utilise the reconstructed figures in the 'Price Per Unit' column to find the item bought in the transaction.
  - Items not identified will be recorded as null.

- Formatting Data:
  - Correcting the decimal points for currency columns.
  - Convert 'Transaction Date' column datatype from 'object' to 'datetime'.
  - Order data by 'Transaction Date', followed by 'Item'.
  - Some column datatypes are 'object' which can display both NaN and <NA> for null values:
    - Convert datatype from 'object' to 'string'.

## Exploratory Data Analysis
### Transaction Value by Item
![Transactional Value by Item](https://github.com/ETAYLOR1111/Data-Cleaning-For-a-Cafe/blob/66c7423eaaddaa3e8e3379064e7fed8466592f6c/Total%20Recorded%20Transaction%20Value.png)
- Salad had the highest total recorded transactional value at £19,070, while Cookies had the lowest at £3,589.
- Meals, particularly Salad and Sandwiches, accounted for the  highest recorded transactional values while drinks and snacks accounted for lower values.
- Items that were unaccounted for generated £5,141 in total transactional value. Additionally, there are values missing in the 'Total Spent' column, meaning that there could be even more transactions not accounted for. Therefore, we cannot provide the total transactional value generated by each item with certainty.
- Unidentified data accounts for 0.4% of dataset entries but represents at least 5.5% of all total transactional value. This could change the distribution of data providing different results. This should be addressed to better understand our data.

### Quantity Sold by Item
![Quantity Sold](https://github.com/ETAYLOR1111/Data-Cleaning-For-a-Cafe/blob/66c7423eaaddaa3e8e3379064e7fed8466592f6c/Quantity%20Sold.png)
- Recorded quantities sold are relatively similar across products, with a range of 572 units between the highest and lowest values. Coffee had the highest recorded quantity sold, while Smoothie had the lowest.
- Items that are not accounted for had a total quantity sold of 1471. This represents at least 4.9% of all sales, and once again could change the distribution of the data.
- One observation would be that Tea and Cookies had very similar sales, but Tea generated £1,877 more in recorded transaction value than Cookies. Further analysis should be conducted to investigate whether differences in price and quantity sold could optimise revenue.

### Monthly Transactional Value
![Monthly Transactional Values](https://github.com/ETAYLOR1111/Data-Cleaning-For-a-Cafe/blob/66c7423eaaddaa3e8e3379064e7fed8466592f6c/Transactional%20Values%20of%20Each%20Month.png)
- In 2023, the month with the highest total transactional value, £7,350, was June, whereas the month with the lowest transactional value was February, at £6,633.50. This is a difference of £716.50.
- Apart from February, the total transactional values across the months of 2023 are stable, with no clear upward or downward trend.
- Through further exploration, £4,165.50 was not assigned a date in 2023. Additionally, values were missing from the 'Total Spent' Column, so we cannot say with certainty that any of these total transactional values for months are accurate. We can say that each month made at least the total transactional values presented in our data. This missing data will alter interpretations of the data.
